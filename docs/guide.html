Horde Expedition · 魔兽风格回合制肉鸽卡牌对战

游戏已经做好，可以玩了。它是一个竖屏网页游戏，项目在 ~/Projects/warcraft-roguelike，开发服务器运行时，浏览器打开 http://localhost:5199/ 就能玩。

我用无头 Chrome 自动跑了几局，覆盖了出牌、回合结算、BOSS 战、战利品选择、前进到下一波和失败界面，没有报错。不过自动脚本出牌很笨，还没赢过一波正常难度的战斗，所以数值平衡只粗调过一次，需要你亲手玩几局来判断。

玩法

  • 回合：每回合 3 点能量、抽 5 张牌。兵牌召唤英雄上场，最多 5 个；法术牌立即生效。点「结束回合」后，英雄按各自技能自动攻击，然后轮到敌人。
  • 英雄（6 个）：
    • 兽人步兵：攻击最前方的敌人
    • 巨魔猎手：连投两次飞斧，优先打残血
    • 牛头人萨满：嘲讽，每回合群体治疗
    • 冰霜法师：攻击全部敌人
    • 矮人狂战士：有几率眩晕目标
    • 月神祭司：治疗血量最低的友军
  • 升星：场上已有同名英雄时再打出这张牌，英雄升一星，最高 5 星。
  • 法术（7 张）：火球术、斩杀、暴风雪、闪电链、治疗波、嗜血术、盾墙。
  • 一路往前打：清空一波后三选一奖励（新卡、修缮大本营、法术强化等），然后背景向前滚动，部落进入下一波。英雄带着血量和星级跟进下一波。
  • BOSS：每 5 波 一个，依次是冰霜骨龙、霜冠巫妖、恐惧魔王，之后循环并逐轮变强。每个 BOSS 每隔几回合放一次大招（冰霜吐息、召唤亡灵加冰冻、邪能火雨），击败后可以选「能量上限 +1」或「全体英雄升星」。
  • 失败：大本营血量归零即结束，会记录最远到达的波次。

素材

  • 立绘和战场背景：是 AI 生成的原创魔兽风格图，没有用网上下载的暴雪原图，避免版权问题。替换成你自己的素材时，把 public/assets/ 里的同名文件覆盖掉就行。
  • 法术图标：下载自 game-icons.net，免费，采用 CC BY 3.0 协议，菜单底部已经加了署名。

需要知道的几点

  • 测试参数：网址后加 ?wave=5 可以直接从指定波次开始，比如直接打 BOSS。
  • 调数值：卡牌、英雄、敌人、BOSS 的数值和波次生成都在 src/data.ts。
  • 背景翻转：为了让背景能无缝循环滚动，战场图做了上下镜像拼接，所以前进几波后会看到倒过来的旗帜和树木。之后要改的话，可以换一张专门做成首尾相接的背景图。
  • 重新启动：以后自己运行用 npm run dev，地址是 http://localhost:5173。
