Horde Expedition · 魔兽风格回合制肉鸽卡牌对战

游戏已经做好，可以玩了。它是一个竖屏网页游戏，项目在 ~/Downloads/git/warcraft-roguelike。在项目目录运行 npm run dev，浏览器打开 http://localhost:5174/ 就能玩。

我用无头 Chrome 自动跑了几局，覆盖了出牌、回合结算、BOSS 战、战利品选择、前进到下一波和失败界面，没有报错。不过自动脚本出牌很笨，数值平衡只粗调过，需要你亲手玩几局来判断。

玩法

  • 回合：每回合 3 点能量、抽 5 张牌。兵牌召唤英雄上场，最多 5 个（前排 3 个、后排 2 个）；法术牌立即生效。点「结束回合」后，英雄按各自技能自动攻击，然后轮到敌人。大本营初始 80 点生命。

    英雄攻 / 血技能
    兽人步兵6 / 24攻击最前方的敌人
    巨魔猎手4 / 15投掷两次飞斧，优先打残血

    冰霜法师3 / 14攻击全部敌人（冰属性）
    矮人狂战士8 / 28攻击前排，35% 几率眩晕（对首领 15%）
    月神祭司2 / 16治疗血量最低的友军 8，并攻击前排
    圣盾卫士5 / 30攻击前排，然后全队获得 3 点护盾
    游侠5 / 18狙击血量最低的敌人，目标半血以下额外 +4
    暗影术士5 / 20攻击前排并按伤害吸血（火属性）
    雷鸣萨满6 / 22闪电攻击最多 3 个敌人，伤害逐次衰减（雷属性）
  • 升星：场上已有同名英雄时再打出这张牌，英雄升一星，最高 5 星。
  • 法术（14 张）：

    集结号令本波全体友军攻击 +2，并获得 4 点护盾
    奥术智慧抽 2 张牌
  • 一路往前打：清空一波后三选一奖励（新卡、修缮大本营、法术强化等），再从路线地图选下一站（见下方「肉鸽系统」）。英雄带着血量和星级跟进下一波。
  • BOSS：每 5 波 一个，依次是冰霜骨龙、霜冠巫妖、恐惧魔王，之后循环并逐轮变强。每个 BOSS 每隔几回合放一次大招（冰霜吐息、召唤亡灵加冰冻、邪能火雨），会先在地上标出预警圈，半血时狂暴化。击败后可以选「能量上限 +1」或「全体英雄升星」。
  • 卡组：主菜单「🃏 卡组」里可以自己组起始卡组，10 到 16 张，每张卡按稀有度有份数上限。
  • 天赋：每局结束按成绩获得天赋点（每清一波 1 点，每击败一个首领再加 2 点），在主菜单「⭐ 天赋」里投入，分大本营、能量、法术、兵种四系，比如城墙加固、能量之泉（能量上限 +1）、法术回响、先祖之魂（新英雄直接 2 星）。随时可以重置。
  • 失败：大本营血量归零即结束，会记录最远到达的波次。

版本更新

这一版加入了 3D 镜头操作、最后一击慢动作，以及九个新玩法：暴击、元素反应、英雄大招、首领预警与换位躲避、首领狂暴化、传说卡「巨龙空袭」、阵营羁绊、遗物和分支路线地图。

所有功能都有自动化测试（.playtest/features.mjs、finale.mjs、orbit.mjs），全部通过。数值是第一版，需要实际玩几局再调。

镜头与动作

  • AI 模型动作：13 个 AI 生成的 3D 模型（6 个英雄、4 种敌人、3 个首领）都绑定了骨骼，有待机、行走、攻击、施法、受击、欢呼、眩晕、死亡 8 套动作。恐惧魔王的翅膀会随动作扇动；冰霜骨龙用单独的四足骨骼，翅膀、尾巴、前爪都会动，攻击是扑咬，施法是仰头吐息。
  • 旋转镜头：在战场空地上拖动可以转动视角，松手后保持不变。双击空地或点右上角「⟲ 视角」回到默认视角。转动后点击单位、技能特效都按实际画面位置计算。
  • 滚轮缩放：在战场上滚动鼠标滚轮可以拉近或拉远，手牌区域滚动不会缩放。
  • 最后一击慢动作：每波最后一个敌人倒下时，画面闪白，上下出现黑边，弹出「最后一击！」，镜头推到敌人身上慢放约 1.5 秒，然后回到你原来的视角，再出胜利横幅。

战斗手感

  • 暴击：英雄攻击基础暴击率 10%，造成 1.8 倍伤害，显示橙色大号「暴击」数字，并有一瞬间的画面停顿和震屏。
  • 击飞：暴击、元素反应或伤害大量溢出的击杀，会把敌人击飞出去。
  • 元素反应：
    • 火打冰冻目标 → 蒸汽爆炸：追加伤害，并溅射周围敌人
    • 物理打冰冻目标 → 碎冰：必定暴击
    • 闪电打灼烧目标 → 超载：引爆灼烧，并弹射一个敌人
    寒冰箭、冰霜法师的大招、巫妖的冰霜新星会造成冰冻（单位上显示 ❄ 并变蓝）。冰霜法师普攻属冰，雷鸣萨满属雷，暗影术士属火，其余英雄是物理。顺序很关键，比如先寒冰箭再火球术。

英雄大招

英雄攻击、受击、击杀都会积攒怒气（血条下方的橙色条）。怒气满时，英雄脚下出现金色光圈，在你的回合点击英雄即可免费释放大招。释放时有过场：慢动作、镜头推向英雄、技能名横幅划过屏幕。

首领战

  • 地面预警：首领每 3 回合会先在英雄脚下标出红色预警圈，下回合再轰击（攻击的 2.2 倍，冰系附带冰冻，火系附带灼烧）。在你的回合里，拖动英雄到别的位置就能躲开，全部躲开会显示「完美闪避！」。冰霜骨龙轰击一整排，巫妖砸 2 个位置，恐惧魔王砸 3 个位置。
  • 狂暴化：首领血量降到一半时触发过场，天色变成血红，首领攻击 +30%，召唤 2 个援军，之后预警范围更大。

传说卡：巨龙空袭

3 费。打出后，一条冰霜巨龙从左下角斜着飞过战场，沿途喷火，对所有敌人造成 16 点火焰伤害，并附加每回合 4 点的灼烧。可能出现在史诗卡奖励和商店里。火焰打中冰冻的敌人同样会触发蒸汽爆炸。

肉鸽系统

  • 站位：前排（上面 3 个位置）受到伤害 -15%，后排（下面 2 个位置）暴击率 +10%。英雄可以随时拖动换位。
  • 阵营羁绊：按场上不同英雄的数量激活，状态显示在左上角，点一下可以看说明。
    • ⚔️ 战士（兽人步兵、矮人狂战士、圣盾卫士）：2 名全体受伤 -1，3 名 -3
    • 🏹 猎手（巨魔猎手、游侠）：2 名暴击率 +15%
    • 🔮 法师（冰霜法师、暗影术士）：2 名法术伤害 +3
    • 🌀 萨满（牛头人萨满、雷鸣萨满）：2 名每回合开始全体回复 4
    • 🌙 精灵（月神祭司、游侠）：2 名怒气获取 +50%
    • 🐗 部落（兽人、巨魔、牛头人、雷鸣萨满）：3 名全体攻击 +2
  • 遗物（12 种，整局生效）：战争号角、嗜血图腾、烈焰之心、永冻之晶、雷霆之锤、怒火徽记、致命匕首、先知法珠、龙鳞护符、屠夫砍刀、先祖王冠、地精金币。精英战和首领战结束后三选一，商店和奇遇里也能拿到。已有遗物显示在左上角，点一下可以看说明。
  • 金币：每波胜利获得金币，精英战双倍，首领战三倍，显示在左上角。
  • 分支路线地图：选完卡牌奖励后选择下一站：
    • ⚔️ 战斗：普通敌人，奖励卡牌和金币
    • 💀 精英：敌人约 1.5 倍强，奖励遗物和双倍金币
    • 🔥 营火：休息（全体回满、大本营 +20）、锻造（随机英雄 +1 星）或冥想（全体怒气充满）
    • 🛒 商店：买卡牌（30 到 120 金币）、遗物（100）、修缮城墙（30）
    • ❓ 奇遇：神秘祭坛、流浪地精、先祖之灵、遗落的宝箱，四选一随机出现
    营火、商店、奇遇不消耗波次，但每段路只能绕道一次。首领战前固定可以先去营火。

相关代码

  • src/run.ts：大招、元素反应、羁绊、遗物、首领预警、路线的数据，调数值主要改这里。
  • src/scenes/route.ts：路线、商店、营火、奇遇、遗物选择界面。
  • src/scenes/BattleScene.ts：战斗逻辑，包括伤害、暴击、反应、大招过场、首领预警、狂暴化、巨龙空袭。
  • src/three/view.ts：镜头旋转、缩放、聚焦和慢动作的共享状态。
  • 「巨龙空袭」同时写在 src/data.ts 和 public/card-data.json 里，因为后者会整表覆盖卡牌数据。卡牌编辑器也支持编辑它。

素材

  • 立绘和战场背景：是 AI 生成的原创魔兽风格图，没有用网上下载的暴雪原图，避免版权问题。替换成你自己的素材时，把 public/assets/ 里的同名文件覆盖掉就行。
  • 法术图标：下载自 game-icons.net，免费，采用 CC BY 3.0 协议，菜单底部已经加了署名。

需要知道的几点

  • 测试参数：网址后加 ?wave=5 可以直接从指定波次开始，比如直接打 BOSS。
  • 调数值：卡牌、英雄、敌人、BOSS 的数值和波次生成都在 src/data.ts。
  • 背景翻转：为了让背景能无缝循环滚动，战场图做了上下镜像拼接，所以前进几波后会看到倒过来的旗帜和树木。之后要改的话，可以换一张专门做成首尾相接的背景图。
  • 重新启动：以后自己运行用 npm run dev，地址是 http://localhost:5174。
  • 3D 模型：主菜单右上角「⚙ 设置」里可以在套装模型和 AI 模型之间切换。AI 模型的原始文件在 .playtest/ai_raw/，骨骼参数在 .playtest/ai_rig_spec.json，用 Blender 运行 .playtest/ai_rig.py 重新绑骨并导出到 public/models/ai/。
